
# EditVillagers ![logo](https://img.shields.io/badge/EditVillagers-modrinth-green%253Flogo%253Dmodrinth%3Flogo%3Dmodrinth%26color%3D%252300AF5C?logo=modrinth&color=%2300AF5C&link=https%3A%2F%2Fmodrinth.com%2Fmod%2Feditvillagers-mod) ![logo2](https://img.shields.io/badge/1.21.10-Fabric-green%3Flogo%3Dfabric?logo=fabric&color=orange)
This is an advanced mod for creating a merchant directly through the GUI menu. It allows you to edit your villager, applying any settings you want, making creating a merchant incredibly convenient and easy!
___
![evlogo](https://cdn.modrinth.com/data/cached_images/797134f1f5172db7480f1fc0f57a17299aeed439_0.webp)
### Commands:
+ /ev create <name> - Create a new villager
+ /ev edit - Opens GUI to edit the villager you're looking at
+ /ev trades - Opens GUI for editing your trades
+ /ev name <name> - Set a custom name for villager (there is support for color codes & and spaces)
+ /ev carry - Move the villager with your gaze (shift key releases the villager)
+ /ev lang - Allows you to change the language of the mod en/ru
___
### Information
+ To start editing a villager, click on "RMB and shift" (alternative /ev edit).
+ Ability to create 80 trades at once using pages in the menu.
+ You can customize your trades for each level of your villager using the options in the menu.
+ The possibility of complete customization of the villager, you can assign a profession and change the appearance!
