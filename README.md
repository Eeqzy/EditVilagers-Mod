
# EditVillagers ![logo](https://img.shields.io/badge/EditVillagers-modrinth-green%253Flogo%253Dmodrinth%3Flogo%3Dmodrinth%26color%3D%252300AF5C?logo=modrinth&color=%2300AF5C&link=https%3A%2F%2Fmodrinth.com%2Fmod%2Feditvillagers-mod) ![logo2](https://img.shields.io/badge/1.21.10-Fabric-green%3Flogo%3Dfabric?logo=fabric&color=orange)
This is an advanced mod for creating a merchant directly through the GUI menu. It allows you to edit your villager, applying any settings you want, making creating a merchant incredibly convenient and easy!

![ㅤ](https://cdn.modrinth.com/data/cached_images/797134f1f5172db7480f1fc0f57a17299aeed439_0.webp)

##  Commands
- **/ev create** _<name>_ - Create a new villager
- **/ev edit** - Opens GUI to edit the villager you're looking at
- **/ev trades** - Opens GUI for editing your trades
- **/ev name** _<name>_ - Set a custom name for villager  _(there is support for color codes & and spaces)_
- **/ev carry** - Move the villager with your gaze _(**shift** key releases the villager)_
- **/ev lang** - Allows you to change the language of the mod _en/ru_

# Main menu
![ㅤ](https://cdn.modrinth.com/data/cached_images/a3bca03294b071e5479b2d299165422347325c89_0.webp)
- This is the main menu of the mod! to start editing a villager, just click on "RMB and shift" and then this menu will open (alternative /ev edit).
- Each button takes you to a specific menu.
- Using the **"Copying"** button, you can copy a villager with the same functionality!
